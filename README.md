# Ayush Thakur Portfolio

A responsive personal resume website built with HTML, CSS and a small amount of vanilla JavaScript.

## Run in VS Code

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension and choose **Open with Live Server**.
3. Keep `style.css`, `script.js`, and `assets/profile.jpg` in their current locations.

The Google Fonts link uses an internet connection; system font fallbacks are included. The page otherwise runs locally without a build step or package installation.

## Project files

- `index.html` — semantic page structure and resume content
- `style.css` — colors, typography, layout, responsive breakpoints and reduced-motion support
- `script.js` — mobile navigation toggle and footer year
- `assets/profile.jpg` — supplied profile photograph
- `CSS_Documentation.pdf` — three-page guide to CSS used in this site

Project descriptions use only the supplied details. The Festive Aura section describes an exploratory attempt that was discontinued, without claiming results or business activity that was not provided.
